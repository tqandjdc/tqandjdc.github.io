由于题目是 attack，肯定有攻击行为，因此查询了以下几个知识点。

目录扫描流量特征

问：在 Wireshark 捕获的流量包中，流量包被进行了扫描目录操作以后所体现的特征是什么？

简单概括： HTTP 请求频率高，随机编写文件路径扫描，服务器返回大量 404，不停试探。

问：怎么分析扫描成功的数据包？

简单概括： 过滤 http.response.code==200。观察返回的 length 字段，过长或过小都可能。请求变换“GET 变 POST”。

WebShell 流量特征

问：哥斯拉流量、蚁剑和冰蝎的流量特征分别是什么？一句话上传木马又是什么？

四、Wireshark 中过滤三大 WebShell 工具的流量

1. 蚁剑（AntSword）

核心过滤规则：

特征依据： 请求体固定以 @ini_set("display_errors","0") 开头，参数名多含 _0x 前缀。

辅助验证：

  • 响应体格式为 随机字符串 + 执行结果 + 随机字符串（如 a1b2c3[whoami结果]d4e5f6）
  • 若使用默认配置，User-Agent 可能含 antsword（但易被修改）

2. 哥斯拉（Godzilla）

核心过滤规则：

特征依据：

  • Cookie 末尾强制带分号（如 session=xxx;）
  • 响应体为 32 位 MD5 拆分结构（前 16 位 + Base64 密文 + 后 16 位）

辅助验证：

  • 请求头 Accept 常为 text/html,application/xhtml+xml;q=0.9
  • 首次连接时存在大体积 POST 请求（传输加密密钥）

3. 冰蝎（Behinder）

核心过滤规则：

特征依据：

  • 密钥协商阶段： GET 请求含 ?pass=随机数（Content-Length 通常为 16）
  • 加密通信阶段： 后续 POST 请求的 Content-Type 为 application/octet-stream，请求体为二进制乱码

辅助验证：

  • 请求头含 Pragma: no-cache 和 Connection: Keep-Alive
  • 特定版本存在固定字节头（如请求头含 dFAXQV1LORc）

此处为简单了解。

一句话木马详解

一句话上传木马：是一段极其精简的恶意脚本代码（通常只有短短一行），它是黑客控制服务器的“后门”。

核心原理： 它利用服务器端脚本语言的代码执行函数（如 PHP 的 eval、ASP 的 execute），来接收并执行黑客通过客户端（如哥斯拉、蚁剑）发送过来的任意指令。

这段代码的意思是：通过 POST 方式接收一个名为 cmd 的参数，并将其中的内容当作 PHP 代码在服务器上执行。黑客只要将这个文件上传到目标网站，就可以通过工具向它发送指令，从而控制整个服务器。

一句话木马的核心是 “用极短代码实现远程控制”，本质是 “接收指令+执行指令” 的组合。它必须配合专用工具（如蚁剑）使用，单独存在时只是普通文本，只有被攻击者触发才会生效。

一、基础语法结构（以 PHP 为例）

所有一句话木马都包含 两个核心部分：

1. 接收指令的部分

从 HTTP 请求中获取攻击者发送的命令，常见方式：

方式 说明
$_POST['密码'] 通过 POST 请求传递（最常用，参数名“密码”可自定义，如 cmd、a）
$_GET['密码'] 通过 URL 参数传递（易被日志记录，隐蔽性较差）
$_REQUEST['密码'] 兼容 GET/POST（最常用变体）

2. 执行指令的部分

将接收到的命令当作代码执行，关键函数：

函数 说明
eval() 直接执行字符串（最经典，但特征明显）
assert() 条件判断式执行（绕过基础检测的常用替代）
create_function() 动态生成函数执行（更隐蔽）

典型示例（PHP）：

  • @ 符号：屏蔽报错信息，避免暴露木马位置
  • cmd：连接密码（攻击者用工具连接时需填写此值）

二、核心特征（快速识别关键点）

1. 极简性

  • 代码长度通常 ≤1 行（50~200 字符），无多余功能（仅接收+执行）
  • 对比大马/小马：
    • 大马：自带文件管理、命令执行等完整功能（代码量大，易被查杀）
    • 一句话木马：必须依赖外部工具（如蚁剑）才能操作服务器

2. 隐蔽性

高频变形绕过检测：

  • 函数拆分： $a='ev'.'al'; @$a($_POST['x']);（避免直接出现 eval）
  • 编码混淆： <?php @eval(base64_decode(...)); ?>
  • 特殊符号： 用 chr(35) 代替 #（如 request(chr(35))）

伪装成正常文件：

  • 插入 404 页面、图片末尾、配置文件中（表面看无异常）

3. 行为特征

  • 无自主动作： 不主动执行命令，只有收到特定请求时才响应（需攻击者用工具触发）
  • 流量特征明显：
    • 请求体含加密指令（如蚁剑流量以 @ini_set("display_errors","0") 开头）
    • 响应体为执行结果 + 随机填充字符（如 a1b2c3[whoami结果]d4e5f6）

四、重要补充说明

  • 合法用途： 安全人员授权渗透测试时用于验证漏洞（未经许可使用即违法）
  • 防御关键：
    • 禁用危险函数：在服务器配置中关闭 eval、assert 等（PHP 的 disable_functions）
    • 监控异常请求：对含 @eval、base64_decode 的流量实时告警
  • 切勿滥用： 一句话木马是典型的攻击工具，私自部署或使用可能触犯《网络安全法》

总结： 一句话木马是 “极短代码+外部工具触发” 的组合，核心特征是代码极简、依赖外部指令、高频变形绕过检测。普通人无需掌握细节，但需牢记：不点陌生链接、不装来源不明软件、定期更新安全防护，即可有效规避风险。
